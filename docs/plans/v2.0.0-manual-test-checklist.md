# v2.0.0 manual soak checklist (release-specific + R8 surfaces)

Two lists: (A) what changed in THIS release and deserves eyes-on, (B) surfaces where
enabling R8/resource-shrinking (new this release) could bite even though the JVM/mock/
instrumented suites are green. Written 2026-09-09 for the maintainer's hand-soak of the
minified verbose-logging release APK — the gate build.gradle itself declares.
