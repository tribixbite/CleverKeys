# v2.0.0 manual soak checklist (release-specific + R8 surfaces)

Two lists: (A) what changed in THIS release and deserves eyes-on, (B) surfaces where
enabling R8/resource-shrinking (new this release) could bite even though the JVM/mock/
instrumented suites are green. Written 2026-09-09 for the maintainer's hand-soak of the
minified verbose-logging release APK — the gate build.gradle itself declares.

## A. Release-specific changes

## B. R8/minification risk surfaces (new this release)

R8 correctness is exactly where static analysis meets reflection/JNI. Suites cover most;
these are worth one manual pass on the minified APK:

- [x] **Cold start + first swipe on a FRESH INSTALL** — ONNX Runtime JNI session init
      under R8 (keep rules for ai.onnxruntime.** incl. nested OrtSession$Result)
- [x] Language switch → second model load (per-language CTC sessions)
- [x] Custom theme JSON save/load (org.json — safe by design, but round-trip is cheap
      to check and covers any field-name-dependent path)
- [x] Compose settings screens all render (Import preview dialog, theme editor,
      sections with the four new controls) — Compose + R8 lambda grouping
- [x] Emoji panel: open, search by keyword, insert (large static tables + keyword index)
- [x] Autofill inline suggestions still appear (service classes are manifest-kept, but
      the inline-presentation path uses framework callbacks)
- [x] TalkBack quick pass: explore-by-touch reads key labels (ExploreByTouchHelper
      virtual views)
- [x] Backup encryption round-trip (Keystore + AES-GCM provider lookup)
- [x] Language-pack import from SAF picker (zip parse + manifest validation + file moves)
- [x] Share/export from playground (FileProvider paths)
- [x] Verbose logging actually logs (this build: LOCAL_BUILD=true — absence of log
      output is itself a red flag per the const-inlining trap)
