# v2.0.0 manual soak checklist (release-specific + R8 surfaces)

Two lists: (A) what changed in THIS release and deserves eyes-on, (B) surfaces where
enabling R8/resource-shrinking (new this release) could bite even though the JVM/mock/
instrumented suites are green. Written 2026-09-09 for the maintainer's hand-soak of the
minified verbose-logging release APK — the gate build.gradle itself declares.

## A. Release-specific changes

### Swipe & dictionary
- [ ] Basic English swipe types the intended word; suggestion bar populates
- [ ] Add a custom word (Settings → Dictionary) with default frequency, then swipe it —
      it should appear top-3 (the calibration fix). Try a cased one ("LaTeX") and
      confirm it commits with its case
- [ ] Possessive proper noun swipes (e.g. Bowie's); contractions display (`dont`→`don't`)
- [ ] Swipe on a non-QWERTY layout (Dvorak/AZERTY) — geometric engine serves candidates
- [ ] Switch language mid-session — layout changes (#160), swipe still works after
- [ ] Delete a custom word that shadows a dictionary word — the dictionary word ranks again

### Theme Creator (all nine fields newly wired)
- [ ] Create a custom theme; set loud distinct colors on: locked-key bg, modifier-key bg,
      special-key bg, activated key border, ripple, suggestion text, suggestion bg,
      high-confidence suggestion, keyboard surface
- [ ] Save while the theme is ACTIVE — keyboard restyles live, no restart
- [ ] Reopen the editor — every field round-trips its saved value
- [ ] Caps-lock (double-tap shift) — locked modifier shows the locked-key color
- [ ] Delete the ACTIVE custom theme — no crash, falls back to default theme (H-2)
- [ ] Built-in themes render unchanged (pixel-identity fallbacks)

### Settings
- [ ] Four new controls exist and persist across IME restarts: Save Media Entries +
      Max Media Size (Clipboard), Show Exact Typed Word (Input Behavior),
      Scale Numpad Height (Appearance)
- [ ] Settings → Reset: custom dictionary, custom layouts and learned data SURVIVE (F-1)
- [ ] Swipe-trail dropdown shows Sparkle and it renders (F-5)
- [ ] PIN Entry Layout switch actually changes the number-entry layout (F-6)

### Default-keyboard reminder (I-7)
- [ ] With another IME default: open a CleverKeys surface — reminder toast appears once
- [ ] Trigger again same boot — no second toast
- [ ] Reboot → one new toast; flip "Default keyboard reminder" off → never again

### Clipboard & GIF

      behind edit mode)
- [ ] Private copy: private entry visible in history, OS clipboard untouched; deleting the
      newest private entry does NOT clear the OS clipboard (D-4)
- [ ] GIF panel: search, scroll past page 1 (pagination), tap inserts the image not a URL

- [ ] Clipboard pane matches theme immediately after a theme change (#130, H-3)

### Playground privacy (I-1)
- [ ] Swipe in the playground — trace count increments
- [ ] Home out, type/swipe in another app, return — count did NOT grow

### Backup/import
- [ ] Export settings; edit a short-swipe mapping locally; import the file with Merge —

- [ ] Encrypted export (.ckenc) round-trips

## B. R8/minification risk surfaces (new this release)

R8 correctness is exactly where static analysis meets reflection/JNI. Suites cover most;
these are worth one manual pass on the minified APK:

- [ ] **Cold start + first swipe on a FRESH INSTALL** — ONNX Runtime JNI session init
      under R8 (keep rules for ai.onnxruntime.** incl. nested OrtSession$Result)
- [ ] Language switch → second model load (per-language CTC sessions)
- [ ] Custom theme JSON save/load (org.json — safe by design, but round-trip is cheap
      to check and covers any field-name-dependent path)
- [ ] Compose settings screens all render (Import preview dialog, theme editor,
      sections with the four new controls) — Compose + R8 lambda grouping
- [ ] Emoji panel: open, search by keyword, insert (large static tables + keyword index)
- [ ] Autofill inline suggestions still appear (service classes are manifest-kept, but
      the inline-presentation path uses framework callbacks)
- [ ] TalkBack quick pass: explore-by-touch reads key labels (ExploreByTouchHelper
      virtual views)
- [ ] Backup encryption round-trip (Keystore + AES-GCM provider lookup)
- [ ] Language-pack import from SAF picker (zip parse + manifest validation + file moves)
- [ ] Share/export from playground (FileProvider paths)
- [ ] Verbose logging actually logs (this build: LOCAL_BUILD=true — absence of log
      output is itself a red flag per the const-inlining trap)
