## What's New in v2.0.0

**Requires Android 7.0+.** The ONNX Runtime upgrade (16 KB page-size support) raises the minimum
from Android 5.0. Devices on Android 5.0–6.0 stay on v1.5.0.

### All-New Swipe Typing
- **New CTC swipe engine, now the default** — on a held-out 2,400-swipe English benchmark it puts
  the intended word first **89.3%** of the time vs **74.6%** for the old transformer engine
- **New geometric engine**: swipe finally works on Dvorak, Colemak, AZERTY, QWERTZ, JCUKEN, Greek
  and custom layouts — no layout is swipe-disabled any more (#9)
- Pick your engine in Settings → Swipe Typing; both get their own settings screen (beam width,
  frequency weight, endpoint tolerance). Every layout/language combination reaches a working decoder
- Contractions display properly (`dont` → `don't`, `cest` → `c'est`) and accents commit (`café`);
  English contractions no longer leak into other languages
- The old neural engine is removed: the app is ~26 MB smaller and uses 30–45 MB less memory while
  swiping. A "Neural"/"Hybrid" engine setting now behaves as CTC

### More Languages
- CTC swipe: English, French, German, Spanish (validated); Italian, Portuguese, Swedish (provisional)
- **Russian** — the first non-Latin script (validation-tested), **early Greek**, and new provisional
  **Ukrainian, Bulgarian, Macedonian and Hebrew** — all via language packs
- Imported Latin-script language packs can swipe too, when the pack is typeable
- Every non-English dictionary rebuilt; ~9,000 new translated strings across 21 locales

### Privacy & Learning
- **"Learn From My Typing" master switch** gates every on-device learning path, with one-tap forget
- Learned words/phrases persist per language, with a browse-and-delete manager and adjustable cap
- **Opt-in next-word prediction** from your own typing
- **Private copy**: copy text straight into CleverKeys' history without touching the OS clipboard —
  key, short-swipe action, selection-toolbar entry, and a "Private only" filter (#156)
- **Encrypted backups** (AES-256-GCM); private entries excluded from plaintext exports
- Fixed: selection history was recorded even with learning off (present since v1.0)

### Custom Words That Actually Swipe
- Custom-word frequencies are calibrated onto each engine's real scale (they used to rank below
  every dictionary word), case handling is fixed, the Android personal dictionary feeds swipe, and
  you're warned when a word is too long for the engine to emit

### Theming, Settings & Accessibility
- Theme Creator's nine broken fields now render: key backgrounds, borders, ripple, suggestion
  colors, keyboard surface — with live preview and no restart
- Four new controls (clipboard media toggle + size cap, exact-typed-word, numpad height scaling);
  Settings reset keeps your dictionary and layouts; landscape height fixed (#161)
- Default-keyboard reminder now fires once per boot, with a permanent "stop asking" switch
- TalkBack support for the keyboard itself: explore by touch, spoken labels, modifier latching

### Clipboard & GIF Panel
- GIF panel crash on Android 7–9 fixed; search pagination fixed; tapping a GIF inserts the image,
  not a dead link (#148/#149); faster category loading on big packs (#152)
- Clipboard media entries can be deleted; themes reach a cached clipboard pane (#130)

### Backup & Quality
- Import preview: merge is import-wins with collisions shown up front; failed imports roll back
  fully; learned data is included in Backup & Restore
- A 69-finding comprehensive audit (all 8 critical findings fixed) swept the IME, dictionary,
  clipboard, GIF, settings, backup and theme layers

Verified by 2,329 pure JVM + 703 mock tests, lint clean.
