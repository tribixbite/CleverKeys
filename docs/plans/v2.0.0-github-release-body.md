## What's New in v2.0.0

**Requires Android 7.0+.** The ONNX Runtime upgrade (16 KB page-size support) raises the minimum
from Android 5.0. Devices on Android 5.0–6.0 stay on v1.5.0.

### All-New Swipe Typing
- **New CTC swipe engine, now the default** — on a held-out 2,400-swipe English benchmark it puts
  the intended word first **89.3%** of the time vs **74.6%** for the old transformer engine
- **New geometric engine**: swipe finally works on Dvorak, Colemak, AZERTY, QWERTZ, JCUKEN, Greek
  and custom layouts — no layout is swipe-disabled any more (#9)
- Pick your engine in Settings → Swipe Typing; both get their own settings screen (beam width,
  frequency weight, endpoint tolerance). Every layout/language combination reaches a working decoder
- Contractions display properly (`dont` → `don't`, `cest` → `c'est`) and accents commit (`café`);
  English contractions no longer leak into other languages
- **Short swipes only** mode (#147, #87): past the short-swipe minimum every gesture types the
  subkey in its direction and is never a word swipe
- A word swiped from a letter whose corner holds a command key (the mic, the clipboard key) stays
  a word; only a short flick into the corner presses the key
- The old neural engine is removed: the app is ~26 MB smaller and uses 30–45 MB less memory while
  swiping. A "Neural"/"Hybrid" engine setting now behaves as CTC

### More Languages
- CTC swipe: English, French, German, Spanish (validated); Italian, Portuguese, Swedish (provisional)
- **Russian** — the first non-Latin script (validation-tested), **early Greek**, and new provisional
  **Ukrainian, Bulgarian, Macedonian and Hebrew** — all via language packs
- **Persian (fa) language pack** (`langpack-fa.zip`, 50,000 words, experimental) and a
  **half-space key** right of the space bar on the Persian layouts
- A layout can name its language (#186, #61), and the Dictionary Manager shows tabs for
  layout-bound languages
- Imported Latin-script language packs can swipe too, when the pack is typeable
- Every non-English dictionary rebuilt; ~9,000 new translated strings across 21 locales

### Voice Input (on device, opt-in)
- **Dictate into any field** with the new Voice input key (Extra Keys) or the `voice_input`
  command: words appear as you speak, the newest underlined until the model confirms them; tap
  again to stop, ✕ to cancel
- Recognition runs on the phone with a **voice pack you import once** —
  `voicepack-moonshine-v2-tiny-en.zip` (English, Moonshine v2 tiny streaming, MIT, ~45 MB) from
  the `langpacks` release. Nothing of the model ships in the APK; every file is size- and
  SHA-256-checked on import
- **Off by default.** The new microphone permission is requested only when you turn voice input
  on or import a pack; audio is never stored and never leaves the device — still no internet
  permission. If Android stops showing the prompt, a dialog opens App info for you
- The existing mic key (`voice_typing`) uses CleverKeys voice once it is on with a pack; its long
  press lists "CleverKeys voice (offline)" beside your system voice keyboards
- Terminals and remote-desktop fields get confirmed words only, appended; password fields refuse
  voice input. Listening stops by itself after about 30 seconds with this pack

### Autocorrect
- **Channel ranking**: candidates rank by edit cost plus a frequency term, so one wrong key is
  never outweighed by a tiny frequency difference (`devixe` → device). On held-out GitHub typos it
  is right 79 % of the time against 54 % for the old ranking. The old ranking stays selectable
- **Ranking & Tuning** (Settings → Auto-Correction): every weight and step is a setting with a
  one-tap reset
- **Unfinished Words**: space no longer turns `tomorr` into `timor` — Keep what I typed (default)
  or Off
- Typo-tolerant tap suggestions (`pka` offers `play`); Hebrew neighbour-key slips are corrected
- **Enter always inserts a new line** switch for multi-line fields (#139)

### Privacy & Learning
- **"Learn From My Typing" master switch** gates every on-device learning path, with one-tap forget
- Learned words/phrases persist per language; the browsers now **search and page through
  everything learned** (no 200-entry cap)
- **Next-word prediction** from your own typing (on by default; toggle in Settings)
- **Private copy**: copy text straight into CleverKeys' history without touching the OS clipboard —
  key, short-swipe action, selection-toolbar entry, and a "Private only" filter (#156)
- **Encrypted backups** (AES-256-GCM); private entries excluded from plaintext exports
- Fixed: selection history was recorded even with learning off (present since v1.0)

### Custom Words That Actually Swipe
- Custom-word frequencies are calibrated onto each engine's real scale (they used to rank below
  every dictionary word), case handling is fixed, the Android personal dictionary feeds swipe, and
  you're warned when a word is too long for the engine to emit

### Looks, Themes and Layouts
- **Familiar looks**: QWERTY (iOS-style), (Gboard-style), (SwiftKey-style) and (Samsung-style)
  layouts each bring that keyboard's look — colours in light and dark, key shapes, hints,
  key-press preview, a three-slot suggestion bar and product-style action keys. iOS 18-style is in
  Theme Manager too. Drawn with CleverKeys' own keys; not affiliated with Apple, Google, Microsoft
  or Samsung
- **Layouts can bring their own look**: a `<theme>` in the layout XML (light and dark), per-row
  and per-key colours, borders and gaps; **Save theme as custom theme**, **Export as layout XML**,
  and a **Keyboard Look** section in the Theme Creator (including the suggestion-bar arrangement)
- **Key spacing and borders per layout** (Layout Manager chip; the Appearance setting stays the
  default)
- **A theme per layout**: bind any theme to a layout; it switches with the layout
- **Custom themes are in the settings export and full backup**
- Theme Creator's nine broken fields now render: key backgrounds, borders, ripple, suggestion
  colors, keyboard surface — with live preview and no restart

### Keys, Gestures and Customization
- **Subkey popover**: hold a key to open a 3×3 grid of its subkeys and slide to one
- **Per-key dialog shows every subkey and where it comes from** (Layout, Built-in, Extra key,
  Hidden, Custom, Removed). Changing a built-in layout's own subkey saves it in a
  "(modified)" copy of the layout, with **Revert to original** in Layout Manager; **Change in all
  layouts** keeps the old global mapping
- **Export XML round trip**: text, key-event, template, timestamp and intent short swipes import
  back as the same action
- Short swipes on Enter, Space and Tab now work and show; **Reset All** asks first and offers Undo
- Template and `'s` macros; editor commands (case cycle, word moves, word and line selection,
  Text Assist / Replace Text results written back)
- **Follow-finger backspace selection** (#190); macron-below and ring-below accents (#187)
- **Quick Settings tile** toggles the keyboard; **Minimize** to a floating button (#175)
- **Use System Vibration** switch (#154); slider stops land on whole values

### Clipboard
- **Swipe a row to delete it**, with a 5 s Undo (#175)
- **Reorder Pinned and To-dos** by drag handle or TalkBack Move up / down / to top
- **Edit very long entries page by page** (over 20,000 characters or 1,000 lines); huge entries no
  longer freeze the pane, and huge pastes are sent in chunks below Android's binder limit
- **Clear the OS clipboard** command (#168); swipe typing goes into the entry editor and the
  keyboard's own search and tag fields, where delete-word now works
- Clipboard media entries can be deleted; themes reach a cached clipboard pane (#130)

### Terminals and Remote Desktops
- Terminals (Termux and others) and blind remote-desktop fields (RustDesk, `TYPE_NULL`) get
  terminal-style input: no rewriting of text the keyboard cannot see, Paste types the clip,
  delete-word is Ctrl+Backspace

### Accessibility
- TalkBack support for the keyboard itself: explore by touch, spoken labels, modifier latching
- **Every key's short swipes are in TalkBack's Actions menu** (Ctrl → "Clipboard manager
  (Southwest)" opens the clipboard pane), including your custom mappings

### GIF Panel
- GIF panel crash on Android 7–9 fixed; search pagination fixed; tapping a GIF inserts the image,
  not a dead link (#148/#149); faster category loading on big packs (#152)

### Settings, Backup & Quality
- Four new controls (clipboard media toggle + size cap, exact-typed-word, numpad height scaling);
  Settings reset keeps your dictionary and layouts; landscape height fixed (#161)
- Default-keyboard reminder now fires once per boot, with a permanent "stop asking" switch
- Import preview: merge is import-wins with collisions shown up front; failed imports roll back
  fully; learned data is included in Backup & Restore
- A 69-finding comprehensive audit (all 8 critical findings fixed) swept the IME, dictionary,
  clipboard, GIF, settings, backup and theme layers

Verified by 3,644 pure JVM and 1,673 mock tests, and 1,646 instrumented tests on Android API
34–37 (1,644 passed, 2 skipped for the test environment), lint clean.
