Reviewer = model (not a native speaker). Enforced by
`TranslationGlossaryTest.everyStringUsesTheLocalesAddressRegister` from
`docs/i18n/glossary.json` (`locales.<l>.register`).

**Trigger.** The on-device test in hu found informal (te) forms, such as "eszközödet",
"megnézhesd" and "törlöd", inside a Privacy section that otherwise addresses the user formally
(Ön): "Ön által", "Koppintson".

AOSP LatinIME decides.

**Decisions.**

## Method

1. `parse_strings.py` unescapes every string/plural item (`\'`→`'`, `\n`→newline, entities).
2. `register_count.py` counts **strings containing at least one marker** of each register.
   Markers are morphological, not just pronouns: 2sg vs 2pl/3sg-polite imperatives, 2nd-person
   verb endings (`-st`, `-ешь`, `-eš`, `-ezi`, `-sin`, `-hatsz`…), possessives (`dein/Ihr`,
   `ta/dvs.`, `твой/ваш`, `-öd/-e`, `-mu/Anda`), pronouns, and for ko/ja sentence-final
   politeness endings. Every hit was printed and read; false positives are listed below and were
   discarded before deciding.
3. Sentence-initial word tallies per locale (imperative discovery) and per-locale suffix scans
   (hu `-sz/-od/-ed/-öd/-d/-j/-hasd/-hesd`, fa `ب-`/`ن-`-initial stems and light verbs `کن/بده/بگیر…`,
   ro `-ezi/-ești`, tr `-sin/-diğin/-ebilirsin` and sentence-final verbs) were used to find forms
   the marker lists missed.
4. Decision = dominant register; AOSP breaks ties. Labels/summaries whose form is
   morphologically ambiguous (ro `Adaugă`, tr `Sil`, es/it/pt/fr `Copia`/`Utilise` = 3sg) are not
   counted as evidence and were not changed.
5. Corrections were applied to copies first (audit scratch scripts, not committed) with
   `apply_corrections.py`, which also checks placeholder multisets, XML round-trip, glossary stems
   (`docs/i18n/glossary.json`) and `TranslationLengthTest` ratios. Forbidden patterns verified by
   `RegisterVerify.java` (real `java.util.regex`, `CASE_INSENSITIVE | UNICODE_CASE`) against the
   original and the corrected trees → `verify_report.txt`.

## Forbidden-pattern verification (summary of `verify_report.txt`)

Java `Pattern.compile(rx, CASE_INSENSITIVE | UNICODE_CASE)` over every unescaped item.
Patterns use `(?<![\p{L}\p{M}])`/`(?![\p{L}\p{M}])` instead of `\b` because Java's `\b`/`\w` are
ASCII-only without `UNICODE_CHARACTER_CLASS`; fa patterns also treat U+200C as a word char.

| loc | patterns | matched before → after |
|---|---|---|
| ro | 4 | 4, 6, 18, 4 → 0, 0, 0, 0 |
| hu | 4 | 0, 1, 1, 1 → all 0 |
| fa | 3 | 10, 0, 0 → all 0 |
| tr | 4 | 0, 0, 0, 1 → all 0 |
| zh-rCN | 1 | 4 → 0 |
| de fr es pt it nl pl cs ru uk lv fil in vi ko ja | 3,3,2,2,2,1,2,3,3,3,3,1,2,1,3,2 | all 0 → 0 (diagnostic guards) |

Patterns deliberately NOT proposed (would false-positive): es `su/sus`, es/pt/fr/it/lv/ro
`-a/-e` imperatives that equal the 3sg indicative, it `Lei/Suo/Sua` (case-insensitive = she/its),
cs `ty/ti` (demonstratives), uk generic `-еш/-иш` (`кеш`), ru `настрой` (noun), lv `atlasi/
skati/raksti/ieraksti` (nouns), vi kinship pronouns (`Anh` = English), tr `-in` possessive
(= genitive), fa bare `دار`/`بین`, ja bare `い`/`た` endings, ko `-해.`/`-야.` (`위해.`).

## Open points / uncertainty (model review)

- **zh-rCN**: dominant 你 (21 strings) wins over 您 (4) by the stated rule, but AOSP and
  Google's mainland UI use 您; flipping is a 21-string edit and the pattern becomes `你`.
- **de**: AOSP LatinIME is du-register; the file is uniformly Sie (43:0), so Sie stands.
- **ro**: the ~150 short-form labels (`Adaugă`, `Șterge`, `Afișează`) are left as the label
  convention; a native reviewer may prefer AOSP-style `-ți` labels. `Vedeți` for "View/See"
  is correct formal Romanian but a noun form (`Afișare…`) would also be acceptable.
- **fa**: 10 rewrites lean on the file's own impersonal/noun conventions; `نگه داشتن`
  ("Keep it") and `پرسیده نشود` ("Don't ask") are natural but not the only options.
- **tr**: register is only visible in user-addressed sentences and `-iniz` possessives; the
  bare-stem label convention means a future informal *instruction* without a final full stop
  (e.g. `Geri almak için tekrar dokun`) would not be caught by pattern 4.
- **es**/**it**/**pt**/**fr**: imperatives cannot be used as markers at all (3sg collisions), so
  those guards rely on pronouns, 2sg verb endings and sentence-anchored instruction shapes.
- pt vocabulary shows a few pt-PT leaks (`arranque`, `predefinido`, `guardar`) — terminology,
  not register; not touched.
