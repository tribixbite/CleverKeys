## P1 — contraction correctness

Source: `docs/proposals/2026-08-18-contraction-handling.md` (full findings table + evidence).

### 4. F1 — tap typing loads the English contraction base for every language

Unguarded transform at `SuggestionHandler.kt:1893,1917`. Exactly two high-frequency casualties:
German `im`@16 → "I'm", French `dont`@104 → "don't". Spanish and Italian top-3000 are clean. The
language-scoped loader needed to fix it **already exists** — this is wiring, not new code. Also
fixes the secondary-language gap (`ManagerInitializer.kt:86-97` never loads secondary-language
contraction files, so `m'appelle` fails when French is the *secondary* language).

### 5. F3 — hyphenated compounds are missing, and they are a DATA fix

`qu'est-ce`, `est-ce`, `peut-être` were never generated. **The "hyphens make this impossible"
assumption is false** — only the KEY must be a–z; the display VALUE is opaque and may carry
hyphens and accents. Proof already shipping: `aujourdhui → aujourd'hui`, `labbe → l'abbé`.
`extract_apostrophe_words.py` only extracts apostrophe words and corpus tokenization splits
hyphens. Regenerate with compounds included. Today a user gets `qu'est` and types `-ce` by hand.

### 6. F6 — no test covers contraction ranking through a real decoder

`ContractionFrequencyTest` was deleted with the neural engine (it exercised
`VocabularyUtils.calculateCombinedScore`). Its scenarios were arithmetic over hard-coded fake
frequencies, so **no real coverage was lost** — but nothing has replaced it. Write pure tests
against the real shipped assets and the real CTC trie, including the one genuinely untested
assertion: a floor-injected alias key surviving the beam into top-K.

Checked and NOT a problem: the `jai`/`jail` inversion risk. `jai` is lexicon-native in French and
`CtcContractionKeys.kt:84` skips native keys, so the floor never touches it; `jail` is not in the
French lexicon at all.

## The geometric-removal question

The maintainer wants nothing falling back to geometric. **Not safely doable today.** The language
dimension is now closed (all 7 bundled dictionary languages run on CTC); what remains is script
and layout:

| cell | blocker | tractable |
|---|---|---|
| 37 of 86 bundled layouts don't declare `script="latin"` | CTC's `ALPHABET` is hardcoded a–z; the model is Latin-trained | **No** — needs a per-script model |
| imported langpacks | CTC reads bundled assets only | **Yes** — λ already known; it's a loader |
| letter-incomplete Latin (`latn_qwerty_az`, `latn_qwerty_tly`) | cannot build a `CtcLayout` without all 26 letters | **Maybe** — needs a relaxation decision |

Geometric's value was never accuracy — CTC beats it by 15–22 points wherever both run. Its value
is that it needs only key positions, while CTC needs a trained model per script. Deleting it does
not downgrade a Cyrillic user; it removes their swipe.

**Russian is the worked example and is DELIVERED on the ML side** (77.92/78.23 in-dict top-1,
val-tier permanently). Remaining work is app-side only — guide §4.6: per-script `ALPHABET` +
`buildMappedLayout`, a second `MODEL_ASSET` with a language→model mapping, the ru langpack, a
golden fixture row, and on-device latency/memory. The `MAX_CHILDREN` cap that would have crashed
on Cyrillic's 33 letters is already fixed (`d671d19e`).

## Rules that must not be broken

1. **No Yandex data** in any training run or shipped artifact — eval-only by licence. `ru-real`
   at 89.64 is better than everything else and permanently unusable.
2. **No FUTO weights or outputs** in anything we train or ship. Corpus + decode-algorithm lineage
   are the permitted inheritance; `NOTICE:46-64` states it correctly — do not "improve" it.
3. **Respect evidence tiers in prose.** "test-validated" = decoded on a sealed split whose read
   was spent from the ledger. Everything else is val-only. Russian is val-only permanently, and
   it/pt/sv are `PROVISIONAL`. Quoting a val-only finalist's number as the ship model's is
   exactly how the `sw2345` misattribution happened — **twice**.
4. **Never route a non-Latin script to CTC** without all three of: a per-script model, a
   per-script trie at the app's own frequency scale, and a golden fixture.
5. **Testing policy**: never test locally via ADB (build-install and log-read only). Write ew-cli
   instrumented or pure JVM tests; if untestable, ask.
6. **`sh gradlew`**, not `./gradlew` (Termux shebang). Temp files go in the session scratchpad,
   never `$TMPDIR`/`$PREFIX/tmp`. Use `rg`, not `grep`.
7. **Rebuild BOTH APKs before an ew-cli run.** `assembleDebugAndroidTest` alone leaves a stale
   app APK and you get `NoSuchMethodError` for code you just wrote. Cost one full run to learn.
